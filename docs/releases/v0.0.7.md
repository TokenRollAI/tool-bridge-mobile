# Tool Bridge Mobile v0.0.7（Preview）

这是供内部验证移动端页面重构的 GitHub Pre-release，不是 production、App Store 或 Google Play 正式
版本。本版本只调整前端导航结构与信箱呈现，不改动本地策略、确认、权限 probe、SQLite 去重、取消、
结果上限、审计边界与任何 capability 契约。

## 本次变化

### 导航精简为三 tab

- 底部导航从六个 tab（状态/信箱/能力/媒体/活动/设置）精简为三个：信箱、活动、设置，信箱升为落地首页；
- 状态、能力、媒体降级为设置页内的二级只读页面，通过根 Stack 独立页面进入并带返回按钮；媒体页面代码
  保留，仅从主导航移出；
- `Screen` 组件新增可选返回按钮；tab accessibility label 与 selected state 语义随之收敛为三项。

### 信箱重做为新闻/邮件式列表

- 信箱由「大卡片 + 平铺元数据 + 折叠正文 + 多按钮」重做为紧凑列表：每条为单行，含未读点、标题、
  来源、相对时间、两行正文摘要与紧急标记；
- 点击整行进入独立消息详情页阅读完整 Markdown，进入即自动标为已读（仅对未读消息触发一次），不再需要
  「查看 Markdown」与单独「标为已读」两个按钮；
- 搜索收进顶部搜索框并由用户显式提交，排序简化为最新/最早/未读优先三档，「全部已读」在无未读时自动隐藏；
- 新增共享 `inboxFormat`（分类/紧急标签与相对时间）与 `InboxMessageScreen`。

### 边界保持不变

- 保留既有安全与无障碍边界：Markdown 图片在用户逐图点按前零网络请求、`sourceCommandId` 等敏感字段不
  进入列表或详情、清空前二次确认、48dp 最小触控尺寸、整行合成可访问名称与离散公告去重；
- 未改动 `phone/inbox.deliver` 契约、SQLite schema、保留上限、通知 payload 或任何执行不变量。

## 安装包与证据边界

Android Preview 包使用 `ai.tokenroll.toolbridgemobile.preview`，内嵌 production JavaScript bundle，
并继续使用内部 debug test key 签名。本地 typecheck、lint、组件/契约测试与单机安装冷启动只证明前端
结构与本地不变量，不能外推为真实 Gateway `inbox/deliver`、信箱图片/搜索/排序真机验收、iOS、
后台/锁屏、弱网、完整 pairing/revoke 或所有 capability 已验收。

pairing、设备专用最小权限 credential、短期 WebSocket ticket、mailbox 与 push 仍未实现。
请勿把 API key、Authorization、SK、敏感 arguments 或原始 WebSocket 失败内容写入日志、
issue 或截图。
