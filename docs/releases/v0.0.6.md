# Tool Bridge Mobile v0.0.6（Preview）

这是供内部验证最新 Tool Bridge device wire 与设备本地信箱的 GitHub Pre-release，不是 production、
App Store 或 Google Play 正式版本。本版本不放宽本地策略、确认、权限 probe、SQLite 去重、
取消、结果上限和审计边界。

## 本次变化

### Device wire

- 将官方 React Native device consumer 从 `@tool-bridge/sdk/device@0.11.0` 升级到精确版本
  `0.14.1`；
- 迁移到命令叶子并入 `path` 的新 call frame，例如 `status/get` 按最后一个 `/`
  归一为本地 `phone/status` + `get`；
- 消费网关签发的 caller、`createdAt` 与 `expiresAt`，并把有效期收紧到本地接收后
  30 秒与网关期限的较早值；旧网关缺少 context 时仍以 credential principal 降级；
- 对无 owner、无命令叶子、空段或尾随斜杠的 direct path 返回 `invalid_argument`，不建立
  mobile 私有协议分叉。
- 由于当天 `expo install --check` 的 SDK 57 兼容表已更新，同步将 Expo 从 57.0.14 升到
  57.0.15，并精确升级门禁点名的 10 个 Expo 配套模块 patch；未跨 SDK，也未新增权限面。

### 设备本地信箱

- 新增 `phone/inbox.deliver` 在线 direct-call 能力，把有界 title、Markdown body、category、urgency、
  可选 Agent `sentAt`/source label 与已读状态保存到本机 SQLite v4 专用内容域；写时保留最近 1,000 条；
- 信箱页支持覆盖全部保留集的参数化搜索、收件/发送时间升降序、已读/未读优先、单条/全部已读和独立清空；
- Markdown 只投影到白名单 React Native 组件，不使用 WebView/HTML/JavaScript。图片在用户逐图点按前零网络，
  点按后可从任意通过本地结构 policy 的标准端口 HTTPS URL 有界下载 PNG/JPEG；无需构建时 hostname 配置；
- 图片请求使用 `credentials: omit`、manual redirect、逐跳/最终 URL 复核以及 redirect、20 秒、3 MiB、
  MIME/签名、4096 单边和 16 MP 上限，校验后只把 App 私有 `file://` 交给 Image；
- `notify: true` 只在消息 commit 后 best-effort 调度固定无正文的本地提醒；提醒失败不回滚消息，
  本地信箱不等于 gateway command mailbox 或 remote push。

## 安装包与证据边界

Android Preview 包使用 `ai.tokenroll.toolbridgemobile.preview`，内嵌 production JavaScript bundle，
并继续使用内部 debug test key 签名。本地构建、覆盖安装/冷启动或单次 Android 真机 `status/get` 返回不能
外推为真实 Gateway `inbox/deliver`、信箱图片/搜索/排序真机验收、iOS、后台/锁屏、弱网、完整
pairing/revoke 或所有 capability 已验收。

pairing、设备专用最小权限 credential、短期 WebSocket ticket、mailbox 与 push 仍未实现。
请勿把 API key、Authorization、SK、敏感 arguments 或原始 WebSocket 失败内容写入日志、
issue 或截图。
