# Tool Bridge Mobile v0.0.4（Preview）

这是供内部验证前端 UI/UX 重构的 GitHub Pre-release，不是 production、App Store 或 Google Play 正式
版本。本版本只重构界面呈现层，未改动本地命令运行时、策略裁决、能力探测或原生权限边界，继续保留
“设备本地裁决优先”的安全边界。

## 本次变化

### 底部标签栏图标（修复）

- 修复安装后底部五个标签页图标为空的问题：`app/(tabs)/_layout.tsx` 此前从未配置 `tabBarIcon`；
- 五个标签页（状态/能力/媒体/活动/设置）现各有图标，选中态用实心、未选中态用描边区分；
- 提高标签栏高度、内边距与标签字号，符合触控人机工程。

### 引入官方图标库

- 新增依赖 `@expo/vector-icons`（SDK 57 配套 `^15.0.2`，实际锁定精确版本 `15.1.1`，MIT 许可，在
  `verify:licenses` 已评审清单内）；
- 通过 `src/ui/components/Icon.tsx` 建立语义图标层：屏幕代码只引用语义名（如 `home`/`media`/
  `warning`），Ionicons glyph 映射集中一处，便于替换；
- 所有图标对辅助技术隐藏（`accessibilityElementsHidden`），只作视觉补充，不承担无障碍语义。

### 设计系统统一

- `src/ui/theme.ts` 新增 `panelElevated` 底色与 `spacing`/`radius` 间距/圆角刻度，替换各组件散落的
  硬编码数值；
- `AccessibleAction` 新增 `primary`/`secondary`/`danger` 三种视觉变体、可选前置图标与按下反馈态；
- `StatusCard`、`Pill`、`Screen` 卡片标题图标徽章、状态圆点与标题栏徽章统一到同一套视觉语言；
- 五个页面与全局确认弹窗（`PendingConfirmationModal`）的空态、操作按钮与状态展示同步更新。

### 无障碍不回退

- 重构全程保持既有的 accessibility label、role、合成语义、48dp 最小触控尺寸、对比度门禁与标签页
  顺序/名称不变；
- `themeContrast` 回归 gate 覆盖新增颜色；285 个单元/组件测试与 typecheck、lint 全绿。

## 安装包

Release 附件中的 `tool-bridge-mobile-preview-v0.0.4.apk`：

- application id：`ai.tokenroll.toolbridgemobile.preview`；
- 内嵌 JavaScript bundle，不需要 Metro；
- 使用自动生成的 Android debug test key 签名，只用于内部安装；
- 同目录 `.sha256` 文件用于核对 APK 完整性。

## 重要限制

- 本次为纯界面呈现层重构，**尚未完成双端真机视觉验收**：标签栏图标实际渲染、图标字体加载、暗色
  主题在不同屏幕密度与系统字号（含 200%）下的表现都需真机/模拟器确认；
- 未开启 Android TalkBack、iOS VoiceOver、Switch Access 或平台朗读/手势顺序的真机可访问性验收；
- 未改动高特权能力、后台前台服务、策略裁决与原生权限；v0.0.3 记录的能力边界与限制继续适用；
- pairing、设备专用最小权限 credential、短期 WebSocket ticket、mailbox 与 push 仍未实现；
- 手工 API key fallback 尚未通过完整 Gateway compatibility matrix；配置保存成功不代表鉴权成功；
- 没有 production signer、AAB、iOS 设备包、商店合规、SBOM、真机矩阵或 staged rollout 证据。

只有 SDK 收到 Gateway `ready` 后 App 才显示 online。请不要把 API key 或原始网络异常写进 issue、日志
或截图。
