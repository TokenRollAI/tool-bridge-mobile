# Tool Bridge Mobile v0.0.9（Preview）

这是供内部验证前台相机拍摄与 Tool Bridge 对象上传的 GitHub Pre-release，不是 production、App Store 或
Google Play 正式版本。本版本新增 `phone/camera.capture_photo`，并将移动端升级到
`@tool-bridge/sdk@0.15.0` 的 context object upload；不放宽系统权限、前台限制、本地策略、确认或审计边界。

## 本次变化

### 仅前台相机

- 新增前后摄像头、low/medium/high 三档 JPEG 拍摄，输出包含稳定 `node://` object reference、尺寸、大小和
  SHA-256，不把照片、私有文件 URI、signed URL 或 EXIF 写入命令结果和普通日志；
- Ask every time / Trusted session 仍先确认，再由用户按快门并复核；Direct call 仍展示可见相机预览，
  预览就绪后自动拍摄并上传，不再要求用户按快门或拍后复核；
- 相机只允许 App 前台 active 状态。进入后台、锁屏、deadline/cancel、权限拒绝或硬件不可用都会拒绝或
  终止命令，不实现隐藏拍摄或后台拍摄；
- 仅声明 Camera 权限，明确关闭麦克风、录音、条码扫描和 EXIF。原始/输出分别限制为 30/10 MiB，按质量
  有界缩放，已知成功、失败、取消和重拍路径 best-effort 清理临时文件。

### SDK 对象上传

- 将 `@tool-bridge/sdk` 精确升级到 0.15.0，使用发布的 `uploadContextObject` 完成 create-upload 与 Blob PUT，
  无需复制或修改上游 SDK 私有源码；
- 上传固定使用 `camera/photos` context 和 `<deviceId>/<sha256(commandId)>.jpg` entry，默认禁止覆盖，并严格
  核对 Gateway 返回的完整稳定 URI；
- create-upload 前重新读取并校验 SecureStore credential；401/403 只清除仍与本次完全匹配的旧凭证，
  不误删已轮换凭证；
- Gateway 部署必须预挂载可写 `camera/photos` R2/S3 context，并为设备凭证配置写 scope。移动端限制不代表
  服务端已经强绑定 commandId、大小、checksum、TTL 或 single-use。

- Android/iOS clean prebuild、原生模块 autolinking 与 production Metro bundle 通过；
