# 启动阅读顺序

每次开始任务依次阅读：

1. `llmdoc/must/project-basics.md`
2. `llmdoc/must/safety-boundaries.md`
3. `llmdoc/must/evidence-language.md`

按任务继续：

- 改 command/runtime、策略、存储或审计：读 `llmdoc/architecture/local-command-runtime.md`。
- 改设备能力或原生模块：读 `llmdoc/architecture/capability-slices.md`。
- 做验证、DOD 或交付结论：读 `llmdoc/guides/verification-and-claims.md`。
- 碰到协议、网关、后台可达或对象传输：读
  `llmdoc/reference/upstream-and-platform-blockers.md`。

已有相关 guide 或 reflection 时，在规划和编辑前主动阅读；事实冲突时回到代码、HTBP 正式规范、
Tool Bridge 已发布 API 和可复现验证记录。
